# بناء APK من غير لابتوب ولا برامج (GitHub)
1. اعمل حساب على github.com واعمل Repository جديد (Public).
2. ارفع كل محتويات الفولدر ده (بما فيهم فولدر .github) باستخدام Add file > Upload files.
3. روح تاب Actions > Build APK > Run workflow. استنى 4-6 دقايق.
4. افتح التشغيل الناجح، ونزّل pharmacy-shelves-apk من Artifacts، فك الضغط وثبّت app-debug.apk.
ملاحظة: لازم تسمح بالتثبيت من مصادر غير معروفة.
