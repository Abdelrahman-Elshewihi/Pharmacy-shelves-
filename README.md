# أرفف الصيدلية

تطبيق ويب ثابت (HTML/CSS/JS) بدون سيرفر ولا build. كل البيانات والصور بتتخزن على الجهاز نفسه (IndexedDB).

## الاستضافة
ارفع الفولدر كله زي ما هو على أي استضافة ملفات ثابتة (Netlify Drop، Cloudflare Pages، GitHub Pages...). لازم HTTPS عشان "تثبيت التطبيق" والعمل بدون نت.

## تنبيهات مهمة
- البيانات محفوظة على نفس **الجهاز + المتصفح + الدومين**. لو غيّرت الدومين أو مسحت بيانات الموقع من المتصفح، البيانات بتضيع.
- الحفظ تلقائي: الصورة بتتحفظ أول ما تختارها، والوصف بعد ما توقف كتابة لحظة.

## تعديل الكود
- `js/config.js` : عدد الأرفف، جودة وحجم الصور، تأخير الحفظ.
- `styles/tokens.css` : الألوان (غيّر `--accent` للون التمييز).
- `js/store.js` : شكل بيانات الرف (ضيف حقول هنا).
- `js/db.js` : التخزين. `js/card.js` : كروت الرئيسية. `js/detail.js` : شاشة الرف.
- بعد أي تعديل وانت مستضيف، لو التطبيق مثبّت على الموبايل اقفله وافتحه مرتين، أو غيّر رقم `CACHE` في `sw.js`.
